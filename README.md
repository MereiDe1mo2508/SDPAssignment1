Short explanation of what I did.
1) I created default class of mannequin as the product that has basic attributes we look at
2) I created both builder class and interface of mannequin to build unique and different items based on default class attributes without worrying if we skipped the important stuff
3) I created many concrete classes that implements into builder interface to simplify it soon in director class
4) I created director class of mannequin to help us build sequence for known and reusable configurations
5) I used Main as the Client class to input data of what we have on our base and test all of our products we input

Main sources of adapting code: GeeksforGeeks, Refactoring guru, many Youtube videos
